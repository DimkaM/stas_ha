# stas_ha

## Цель проекта

Контроль водоснабжения и теплоснабжения частного дома.

В частности:

Контроль давления воды, для своевременной подкачки гидроаккумулятора.

Контроль температуры воздуха для избежания замерзания воды.

В качестве ПО используется Home Assistant

## Используемые материалы

### Контроллер esp32c3

PlatformIO

### АЦП ADS1115

### Датчик давления 

Рабочее напряжение: 5 В постоянного тока
Выходное напряжение: 0,5-4,5 В постоянного тока
Материал: Металл + АБС
Рабочий ток: менее 10 мА
Диапазон рабочего давления: 0-1,2 МПа

## Что сделано

Для датчика давления делитель напряжения.
Резисторы R1 = 3.0кОм, R2 = 8.2кОм
