# stas_ha

## Цель проекта

Контроль водоснабжения и теплоснабжения частного дома.

В частности:

- Контроль давления воды, для своевременной подкачки гидроаккумулятора.
- Контроль температуры воздуха для избежания замерзания воды (в перспективе).

В качестве ПО используется Home Assistant (HA).

**Подробное состояние работ, схема подключения и инструкции по сборке —
в [PROGRESS.md](PROGRESS.md).**

## Используемые материалы

### Контроллер ESP32-C3

Прошивка на PlatformIO (framework Arduino, C++17).

Подключение к ПК: USB-UART мост CH343 (`1a86:55d3`), под Linux — `/dev/ttyACM0`,
SerialNumber `5B14142211`; под Windows — виртуальный `COMx`.

### АЦП ADS1115

16-битный I2C АЦП, адрес **0x48** (`ADDR` → GND), питание 3,3 В, вход A0,
усиление `GAIN_ONE` (±4,096 В).

### Датчик давления

- Рабочее напряжение: 5 В постоянного тока
- Выходное напряжение: 0,5–4,5 В постоянного тока
- Материал: Металл + АБС
- Рабочий ток: менее 10 мА
- Диапазон рабочего давления: 0–1,2 МПа (0–12 бар)

## Схема подключения

### ESP32-C3 ↔ ADS1115

| ESP32-C3 | ADS1115 |
|---|---|
| `3V3` | `VDD` |
| `GND` | `GND` |
| **GPIO5** | `SDA` |
| **GPIO6** | `SCL` |
| — | `ADDR` → `GND` (адрес 0x48) |
| — | `ALRT` — не подключён |

### Датчик давления

| Датчик | Куда |
|---|---|
| `VCC` | 5 В (с ESP32-C3, VBUS/USB) |
| `GND` | `GND` (общая земля с ESP32 и ADS1115) |
| `OUT` | делитель R1/R2 → `A0` ADS1115 |

Делитель напряжения (R1 = 3,0 кОм последовательно, R2 = 8,2 кОм на землю):

```
Датчик OUT ──[ R1 3k0 ]──┬── ADS1115 A0
                          │
                      [ R2 8k2 ]
                          │
                         GND
```

Максимум 4,5 В на выходе датчика → 3,30 В на входе АЦП (в пределах допустимого).

## Что сделано

- Для датчика давления делитель напряжения: R1 = 3,0 кОм, R2 = 8,2 кОм.
- Создан проект PlatformIO: `platformio.ini`, `src/main.cpp`, `include/config.h`.
- Прошивка читает давление через ADS1115 и публикует его в MQTT с
  автообнаружением в Home Assistant (устройство «stas_ha pressure»).

## Быстрый старт

```bash
# Linux
./pio.sh run -t upload
./pio.sh device monitor

# Windows
pio run -t upload
pio device monitor -b 115200
```

Перед сборкой:

1. скопировать `include/secrets.h.example` → `include/secrets.h` и заполнить
   WiFi SSID/пароль и адрес MQTT-брокера Home Assistant;
2. указать COM-порт в `platformio.ini` (`upload_port` / `monitor_port`).
